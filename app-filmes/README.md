# CinemaBook

Aplicativo mobile para gerenciamento de filmes desenvolvido em React Native com Expo.

## Funcionalidades

- Listar filmes
- Buscar por nome
- Filtrar por gênero
- Adicionar filmes
- Editar filmes
- Excluir filmes
- Avaliar filmes com estrelas

## Tecnologias

- React Native
- Expo
- React Navigation
- Axios

## Executar

```bash
npm install
npx expo start
